## 📚 Chapter 02. Task별 실전 인퍼런스 마스터 - 섹션 2.2 NLP (자연어 처리) 실습

### 🎬 도입 스토리

여러분은 이제 막 대형 이머커스 기업의 'AI 서비스팀'에 합류했습니다. 팀장님이 첫 과업을 주셨네요. "우리 쇼핑몰에 하루 10만 건 이상의 리뷰가 올라오는데, 이걸 사람이 다 읽을 수 없으니 **1. 어떤 리뷰가 화가 나 있는지(감성), 2. 어떤 제품이나 브랜드 언급이 있는지(개체명), 3. 긴 불만 사항을 한 줄로 요약(요약)** 해서 대시보드에 뿌려주는 자동화 시스템을 구축해 주세요."

이것은 전형적인 **VOC(Voice of Customer) 분석 시스템**의 핵심입니다. 개발자는 이런 요청을 받았을 때 "모델 3개를 따로 돌려야겠네"라고만 생각하지 않습니다.

"세 모델을 동시에 돌릴 때 메모리 점유율(VRAM)은 괜찮을까?", "요약 모델은 연산량이 많은데 실시간 처리가 가능할까?", "한국어 특유의 중의적 표현을 개체명 인식기가 잘 잡아낼까?"와 같은 엔지니어링적 고민을 시작합니다. 오늘 우리는 이 세 가지 태스크를 실무 수준에서 결합하고, 그 이면의 동작 원리를 파헤쳐 보겠습니다.

---

### NLP의 3대 핵심 태스크

* **감성 분석 (Sentiment Analysis)**: 문장 전체의 톤을 분류합니다. (Sequence Classification)
  
* **개체명 인식 (NER, Named Entity Recognition)**: 문장 내 단어별로 '이름', '장소', '제품명' 등의 딱지를 붙입니다. (Token Classification)

* **요약 (Summarization)**: 긴 지문을 핵심 의미를 유지한 채 짧게 생성합니다. (Sequence-to-Sequence)

### 내부 동작 원리 (The "Head" Concept)

가장 중요한 개념 중 하나는 **"Base Model 위에 Head가 붙는다"** 는 것입니다.

* **구조적 관점 (Heads)**:
  * **감성 분석**: BERT 같은 모델 맨 위에 '분류용 레이어(Linear Layer)' 하나가 붙습니다. 주로 `[CLS]` 토큰의 벡터값만 사용하여 문장 전체를 판단합니다.
  
  * **개체명 인식 (NER)**: 모든 토큰 각각의 위치 위에 분류 레이어가 붙습니다. 단어 하나하나가 '인물'인지 '조직'인지 판단해야 하기 때문입니다.
  
  * **요약**: 문장을 이해하는 **Encoder**와 문장을 새로 쓰는 **Decoder**가 쌍으로 움직입니다. (BART, T5 모델 등)


* **메모리 및 연산 복잡도 ($O(n^2)$)**: <br>
자연어 처리 모델의 핵심인 'Self-Attention'은 입력 문장 길이($n$)의 **제곱**에 비례하여 연산량과 메모리가 늘어납니다. <br>
따라서 요약 태스크처럼 입력이 긴 경우, 문장 길이를 조금만 줄여도 서버 비용을 획기적으로 아낄 수 있습니다.

### 실행 흐름: 모델별 데이터 흐름

1. **감성 분석**: `Text -> Tokens -> [CLS] 벡터 추출 -> Classifier -> Label`
   
2. **NER**: `Text -> Tokens -> Every Token 벡터 추출 -> Classifier per Token -> Entity Labels`

3. **요약**: `Text -> Encoder (의미 압축) -> Decoder (한 단어씩 생성) -> Summary Text`

### 주의사항 및 베스트 프랙티스

* **슬라이딩 윈도우(Sliding Window)**: 모델이 처리할 수 있는 최대 길이(보통 512토큰)보다 긴 리뷰가 들어오면, 앞부분만 잘리는 현상이 발생합니다. 이를 방지하기 위해 긴 문장을 쪼개서 처리한 뒤 결과를 합치는 전략을 씁니다.
  
* **한국어 전용 모델 선택**: 영문 기반 다국어 모델(BERT-base-multilingual)보다는 한국어로만 학습된 모델(KoBERT, KoELECTRA)이 한국어 특유의 조사나 어미 변화를 훨씬 잘 이해합니다.

### 🎓 핵심 요약

**이번 섹션에서 배운 것:**
1. **NLP 3대 태스크** - 감성(전체 분류), NER(단어별 분류), 요약(생성)의 차이와 용도를 익혔습니다.
2. **Head 아키텍처** - 모든 NLP 모델은 공통의 Base(뇌) 위에 각 목적에 맞는 Head(도구)를 갈아 끼우는 구조임을 이해했습니다.
3. **실무형 엔진 설계** - 단순히 모델을 돌리는 것을 넘어, 비즈니스 로직(길이 제한, 키워드 필터링)을 결합하는 법을 배웠습니다.
